# Estilos del proyecto

Al crear o modificar estilos o clases de las plantillas, lee y aplica estas dos skills locales:

- [scss-bem](.agents/skills/scss-bem/SKILL.md): escribir los estilos en SCSS y nombrar las clases de componentes con BEM.
- [style-architecture](.agents/skills/style-architecture/SKILL.md): reutilizar la API y las clases compartidas de `src/styles` antes de añadir estilos locales.

Estas reglas se aplican a todo el proyecto. Conserva las clases de utilidades compartidas con sus nombres existentes.
